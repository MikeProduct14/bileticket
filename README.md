# Туда‑сюда

Мобильный HTML‑прототип покупки междугороднего автобусного билета. Данные расписания, резервы, платежи, профиль и возвраты демонстрационные.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Откройте [главную](http://localhost:4173/) или [Москва → Ставрополь](http://localhost:4173/avtobusy/moskva/stavropol/). В выдаче раскройте «Демонстрационные состояния», чтобы проверить пустое расписание, потерю места, изменение цены, неопределённую оплату и другие состояния. В анкете можно нажать «Заполнить примером». Если доступных рейсов на текущую дату нет, выберите другой день или сценарий «Все типы рейсов».

## Статическая сборка

```sh
npm run build
```

Готовые HTML‑страницы и локальные ресурсы лежат в `dist/`. Раздавайте этот каталог с корня HTTP‑сервера. Для просмотра выдачи по параметру даты с отключённым JavaScript используйте `npm run dev`. Статическая сборка содержит расписание на дату сборки и обновляет выбранную дату в браузере.

Канонические пути, заголовки и обычные ссылки на направления доступны в исходном HTML. Все страницы демо закрыты через `noindex`. Публикация расписания и sitemap потребует подтверждённых данных перевозчика и рабочего домена.

Личные данные анкеты хранятся в памяти до обновления страницы. В текущей вкладке сохраняются тестовый номер заказа, состояние оформления и признаки демопрофиля. Для повторной покупки профиль подставляет только встроенные вымышленные контакты.

Для публикации из подпапки используйте `npm run build -- --base /bileticket`. Для сборки версии в другой каталог добавьте `--out /путь/к/каталогу`.

## GitHub Pages

Текущая сборка публикуется из `main`. Для сохранения выпуска создайте Git‑тег формата `vX.Y.Z` и отправьте его вместе с коммитом. Workflow **Deploy GitHub Pages** добавляет сайт из каждого такого тега в архив `versions/`. Старые теги сохраняют свои адреса и исходники.

Для локальной проверки всех версий запустите `node --test` и `node scripts/build-pages.mjs`. Результат второй команды — `dist-pages/`. GitHub Pages раздаёт этот каталог под префиксом `/bileticket/`.
